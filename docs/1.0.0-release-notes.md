# 1.0.0 Release Notes

## Overview

This is the first release of the Azure Event Hubs connector under the new multi-version targeting build system. Packages are now published per CluedIn version with a version suffix in the package name, replacing the previous single-package approach.

## Multi-version targeting

Packages are now built and published for each supported CluedIn version simultaneously:

| Package | CluedIn version | Target framework |
|---|---|---|
| `CluedIn.Connector.AzureEventHub.460` | 4.6.x | net6.0 |
| `CluedIn.Connector.AzureEventHub.470` | 4.7.x | net6.0 |
| `CluedIn.Connector.AzureEventHub.480` | 4.8.x | net6.0 |
| `CluedIn.Connector.AzureEventHub.50` | 5.0.x | net10.0 |

## Notes

- Package versioning has been reset to `1.0.0`. Previous package versions (3.x, 4.x) were published under the old single-package scheme and are not compatible with this release.
- See `docs/multi-version-targeting-migration.md` for details on how the build system was migrated.
